## Context

Legacy chat nhận senderId từ payload và joinConversation thiếu membership guard; conversation chỉ private/group.

## Options

| Phương án | Trade-off |
| --- | --- |
| Raw WebSocket mới | Tự xây ack/reconnect/rooms; tốn rewrite UI. |
| Socket.IO với client tự khai actor/room | Ít sửa nhưng có impersonation và room enumeration. |
| Socket.IO JWT + server ACL | Chọn đề xuất, gần legacy và kiểm quyền mọi action. |

## Proposed decision

Handshake JWT + origin allowlist; derive sender từ claims. Namespace /social, path /socket.io; PASS_BOOKING contextId=postId + seller/buyer pair unique. Persist message trước ack, unique clientMessageId theo actor/room; Mongo history; Redis chỉ fan-out.

## Consequences và điều kiện cần chốt

Revocation/expiry và membership phải kiểm cả reconnect/action, không chỉ handshake. Post close đề xuất read-only; trạng thái không xác minh được thì fail-closed write. Out-of-order event cần version/reconcile.

## Migration / rollback

Rollout Socket version cùng UI adapter; tắt action chưa kiểm ACL thay vì mở fallback anonymous. Có thể chạy một replica trước, thêm Redis khi có nhu cầu.
