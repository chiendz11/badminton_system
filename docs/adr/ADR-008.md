## Context

Kiến trúc/Excel yêu cầu read-only; AI trong repo mới đã có execution đặt sân sau xác nhận. Đây là xung đột sản phẩm đang mở, không chỉ lựa chọn thư viện.

## Options

| Phương án | Trade-off |
| --- | --- |
| Giữ execution hiện tại | Phù hợp BRD baseline, cần bỏ hoặc sửa no-write goal trong kế hoạch mới. |
| Read-only profile theo tài liệu mới | Đề xuất cho V2: FAQ/tìm sân/gợi ý, bàn giao sang UI; cần cutover runtime. |
| Hai profile cùng lúc | Phức tạp quyền và UI; chỉ làm nếu có yêu cầu rõ và policy tách biệt. |

## Proposed decision

Đề xuất chọn read-only cho V2, tools allowlist search_centers/get_pricing/search_availability/search_faq, không Core SQL credential, không tool ghi. CHƯA áp dụng, chờ Người 1/2/5 và chủ sản phẩm chọn. FastAPI + retrieval baseline, LLM optional qua provider adapter; không tự chọn model chưa đo.

## Consequences và điều kiện cần chốt

Cần workflow/UI migration, no-write/ACL abuse tests, golden labels, retrieval/model evaluation. 300 FAQ rows không phải accuracy evidence. Fake golden chỉ hồi quy. Mọi tuyên bố no-write gate hiện tại đều chưa hợp lệ khi execution vẫn bật.

## Migration / rollback

Giữ runtime hiện tại trong lần docs/skeleton. Nếu chọn read-only, rollout feature flag/route version có fallback UI và session migration. Nếu giữ execution, cập nhật BRD/contracts/Excel policy trước khi Accepted.
